# Whop Platform Features

Reference from docs.whop.com for building demo apps.

## Embedded Components

| Component | Description | Use Case |
|-----------|-------------|----------|
| **Embedded Checkout** | Drop-in payment UI | Buy buttons, subscription CTAs |
| **Embedded Payouts** | Balance display, withdraw, payout methods, KYC | Creator/seller dashboards |

## APIs

| API | Description | Use Case |
|-----|-------------|----------|
| **OAuth** | Login with Whop | User authentication |
| **Memberships** | Subscriptions, access passes, recurring billing | Subscription products |
| **Chat** | Channels, DMs, moderation | Messaging features |
| **Forums** | Posts, comments, threads | Community discussions |
| **Courses** | Chapters, lessons, progress tracking | Educational content |
| **Notifications** | Push alerts to users | Reminders, updates, alerts |
| **Webhooks** | Event callbacks (payment.succeeded, etc.) | Backend automation |
| **Payments** | Create, retry, void, refund | Payment management |
| **Invoices** | Create and manage invoices | Billing |
| **Files** | Presigned URLs, file storage | Media uploads |

## Payout Infrastructure

- Revenue sharing per transaction
- Multiple payout destinations (bank, PayPal)
- Ledger account tracking
- Withdrawal requests with receipts
- Connected account onboarding

## Other Features

- Promo codes
- Affiliate programs
- License keys
- Waitlists
- Team roles & permissions
